Política de Privacidade

TikTok Sync — última atualização: 29 de setembro de 2026

Esta política descreve como o aplicativo TikTok Sync ("o aplicativo") trata os dados ao integrar-se ao Google Drive. É um aplicativo de uso pessoal, operado pelo próprio usuário em seu computador.

1. Dados que o aplicativo acessa

O aplicativo utiliza a API oficial do Google Drive, com autorização do usuário via OAuth 2.0, para:

  • listar e ler pastas e arquivos de vídeo indicados pelo usuário;
  • baixar esses vídeos para o computador do usuário;
  • renomear e enviar vídeos finais de volta ao Google Drive do usuário.

O aplicativo acessa somente os arquivos da conta do próprio usuário, e apenas para as finalidades acima.

2. Como os dados são usados

Os dados acessados são usados exclusivamente para sincronizar os vídeos entre o Google Drive e o computador do usuário. O aplicativo não vende, não compartilha e não transfere os dados do usuário a terceiros. O uso das informações obtidas da API do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

3. Armazenamento e segurança

  • As credenciais de acesso (tokens) ficam armazenadas de forma segura no próprio computador do usuário (Gerenciador de Credenciais do Windows), nunca em texto puro.
  • Os vídeos baixados ficam apenas no computador do usuário.
  • O aplicativo não possui servidores próprios e não envia dados a nenhum serviço além do próprio Google Drive do usuário.

4. Compartilhamento com terceiros

Nenhum dado do usuário é compartilhado com terceiros.

5. Revogação de acesso

O usuário pode revogar o acesso a qualquer momento na página de segurança da sua Conta Google, em myaccount.google.com/permissions.
